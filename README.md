# آب‌بها

آب‌بها یک وب‌اپلیکیشن برای محاسبه و تقسیم هزینه آب ساختمان است.

این پروژه با هدف ساده‌تر کردن محاسبه سهم واحدهای یک ساختمان از مبلغ قبض آب طراحی شده است.

## قابلیت‌ها

- تقسیم قبض بر اساس مصرف کنتورهای فرعی
- تقسیم با استفاده از کنتور اصلی و محاسبه اختلاف مصرف
- تقسیم قبض بر اساس تعداد نفرات
- پشتیبانی از تاریخ شمسی
- ثبت مهلت پرداخت
- امکان ثبت شماره کارت ساختمان
- ثبت توضیحات
- نمایش مجموع مصرف
- خروجی چاپ
- خروجی PDF
- خروجی Excel
- طراحی واکنش‌گرا برای استفاده در دسکتاپ و موبایل

## روش‌های محاسبه

### مصرف کنتورهای فرعی

در این روش مبلغ قبض بر اساس میزان مصرف ثبت‌شده برای کنتور هر واحد تقسیم می‌شود.

### کنتور اصلی و تقسیم اختلاف

در این روش مصرف کنتور اصلی با مجموع مصرف کنتورهای واحدها مقایسه شده و اختلاف مصرف در محاسبه هزینه لحاظ می‌شود.

### تعداد نفرات

در این روش سهم هزینه هر واحد بر اساس تعداد نفرات ساکن در آن محاسبه می‌شود.

## تکنولوژی

آب‌بها یک وب‌اپلیکیشن سمت کاربر است و با استفاده از فناوری‌های زیر توسعه داده شده است:

- HTML
- CSS
- JavaScript

## اجرا

برای اجرای پروژه، فایل `index.html` را از طریق یک وب‌سرور محلی یا سرویس میزبانی وب اجرا کنید.
